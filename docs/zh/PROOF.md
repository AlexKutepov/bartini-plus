# 证明与推理：巴尔蒂尼与巴尔蒂尼+

**假说与检验：** 亚历山大·库捷波夫（Alexander Kutepov）与大语言模型（LLM）。  
**记录日期：** 2026年8月31日。  
**状态：** 公开研究。并未证明物理宇宙是六维的。巴尔蒂尼+的数值推论已检验。

本文记录完整推理链：从 R. O. di Bartini 的构造，到随机扩展，再到实验 L0–L3。

---

## 0. 对象

罗伯托·奥罗斯·迪·巴尔蒂尼（罗伯特·路德维戈维奇·巴尔蒂尼）把实在写成六维：三个空间坐标、三个时间坐标。物理量写成 \(L^a T^b\)。

标准物理：

\[
(x,y,z,t),\qquad 3+1.
\]

巴尔蒂尼：

\[
(x,y,z,t_1,t_2,t_3),\qquad 3+3.
\]

任务：把巴尔蒂尼数学中真正推出的内容，与后来的解读分开；补上选择可观测时间的机制；再做检验。

---

## 1. 巴尔蒂尼的历史构造

### 1.1. 量纲矩阵

基本范畴：\(L\)（长度）、\(T\)（时间）。量是 \(L^a T^b\)。

\[
v=LT^{-1},\qquad a=LT^{-2}.
\]

量纲分析只定类 \([Q]\)，不定无量纲系数（\(\alpha\)、\(m_e/m_p\)）。在写出具体公式、输入量与自由参数个数之前，“巴尔蒂尼推出了全部常数”不成立。

### 1.2. 六维作为乘积

\[
M_6=M_3^{\mathrm{space}}\times M_3^{\mathrm{time}},
\]

“(3+3) 维复流形”：三维类空延拓，与正交的三维类时延拓。

### 1.3. “世界变体”与“时间速度”

额外时间轴有时被读成历史分支。仅有坐标得不到多世界诠释。多世界需要希尔伯特空间、幺正演化、退相干与测度。三条轴 \(t_\alpha\) 不是三条命运。

“时间速度 / 时间高度”指内时间空间中的位置。巴尔蒂尼已知文本里没有现成的选轴定律。

## 2. 数字 6 的推导（可复现）

### 2.1. 函数与积分

对 1965 年工作的复原使用

\[
j(n)=n^n e^{-\pi n^2},
\]

以及与跃迁期望相关的

\[
m(n)=\int_0^\infty x^n e^{-\pi x^2}\,dx=\dfrac{\Gamma\bigl(\tfrac{n+1}{2}\bigr)}{2\pi^{(n+1)/2}}.
\]

### 2.2. 极值

\[
\psi\bigl(\tfrac{n+1}{2}\bigr)=\ln\pi,
\]

数值解：

\[
\frac{n+1}{2}\approx 3.628473202,\qquad n_*\approx 6.256946404.
\]

巴尔蒂尼表中 \(n+1=+7.256946404\)，同一 \(n_*\)。

### 2.3. 最近整数

\[
m(5)\approx 0.03225,\quad m(6)\approx 0.03024,\quad m(7)\approx 0.03080,
\]

\[
m(6)<m(5),\quad m(6)<m(7).
\]

整数局部最小在 \(n=6\)。

### 2.4. 这不能证明什么

1. \(j(n)\) 与 \(a=\pi\) 并非由物理推出。换 \(a\)，极小值移动。
2. “\(m(n)\) 的极值 ⇒ 物理维数”是额外公设。
3. \(6.2569\to 6\) 的取整是额外假定。
4. \(n=6\) 推不出 \(3+3\)。\(5+1\)、\(4+2\) 均可。分裂是公设。

**条件定理。** *对此 \(m(n)\) 与 \(a=\pi\)，连续极小的最近整数是 6，且在 \(\mathbb{Z}\) 上局部最小。*  
**不是定理。** *宇宙是六维的。*

## 3. \(3+3\) 几何

### 3.1. 平坦度量

\[
ds^2=dx^2-c^2(dt_1^2+dt_2^2+dt_3^2),\qquad \eta_{AB}=\mathrm{diag}(1,1,1,-1,-1,-1).
\]

签名 \((3,3)\)。数学上合法。

### 3.2. 测地线

克里斯托费尔符号为零。自由运动是直线。按 \(|u|^2-|w|^2\) 分类类时 / 零 / 类空。

### 3.3. 得到 \(3+1\) 观察者的两种办法

**总时间** \(dT=c^{-1}|dq|\) 沿轨迹给出类狭义相对论间隔。\(T\) 是内时间路径长，不是一只钟的读数。

**单一坐标** \(t=t_1\) 使 \(t_2,t_3\) 上的隐蔽运动看起来超光速。普通狭义相对论需要手工令 \(dt_2=dt_3=0\)。

**结论。** \(3+3\) 包含作为切片的 \(3+1\)。它不解释为何实现的是这一片。

### 3.4. 动量与质量

无质量 6-粒子满足 \(|p|^2=|\pi|^2\)。投影到 \(t_1\) 得 \(m_{\mathrm{eff}}^2\le 0\)（快子符号）。总时间 \(T\) 给出 \(E_T=c|p|\)——仍无质量。需要额外机制。

### 3.5. 波动方程与柯西问题

\((3,3)\) 波动算子是超双曲的。隐蔽频率超过 \(c|k|\) 时，\(t_1\) 振幅指数增长。对任意初值，\(t_1\) 上的柯西问题不适定。需要非局域谱约束。巴尔蒂尼的通常叙述没有这一机制。

### 3.6. 因果

三个时间方向：没有典范的先后。零锥与 \(S^2\times S^2\) 相关。紧致时间几乎必然产生闭合类时曲线。

## 4. “每一瞬间选择 \(T\)”的假说

想法：每一瞬间从 \(t_1,t_2,t_3\) 中选出一个方向，世界变成 \(3+1\)。

这**不是** \(3+3\) 度量的推论，而是额外公设。

- 可观测时间可以是任意 \(T=n\cdot t\)，\(n\in S^2\)。选项是连续统，不是三个点。
- “每一瞬间”需要元参数 \(\lambda\)，否则用尚未选出的时间来为选择计时。
- 随机规则需要概率、选择载体与观察者一致。
- 常规实验看不到时间流的跳跃；若机制存在，它被隐藏。

无随机瓮的三种读法：

| | 内容 | 选轴 |
|---|---|---|
| A | 静态 6D 块，我们的世界是切片 | 无 |
| B | 动力学方向 \(n(x)\) | 定律 / 观察者 |
| C | 历史分支 | 需要量子测度 |

巴尔蒂尼更接近几何纲领 A。逐瞬选择是附加层。

## 5. 巴尔蒂尼+ 公理

**P1.** 坐标 \((x_i,t_\alpha)\)，度量 \(ds^2=dx^2-c^2\sum dt_\alpha^2\)。

**P2.** 元步 \(k=0,1,2,\ldots\)。每步恰好一只钟 \(\alpha_k\) 走一步。

**P3.** 场随打勾的钟演化。数值上，复振幅 \(\psi\mapsto\psi\exp(-i c_\alpha k\Delta t)\)。不同钟可带不同 \(c_\alpha\)。

**P4.** 可观测时间 \(T=\varepsilon k\)。单独的 \(t_\alpha\) 不可观测。

**P5.** \(p_\alpha\propto n_\alpha^\theta\)。\(\theta>1\) 时为非线性波利亚瓮（报酬递增）。

**P6.** 观察者是场 / 元胞自动机内部的结构。

这不是历史上的巴尔蒂尼。

## 6. 解析推论

### 6.1. 锁定 \(3+3\to 3+1\)

\(\theta>1\) 时过程几乎必然锁到一个顶点：\(p\to\delta_{\alpha,\alpha^*}\)。对称初值下赢家随机。\(t_2=t_3=\mathrm{const}\) 动态出现。不同实现锁到不同轴：世界树是系综统计。

\(\theta=0\)：均匀 \(p\)，不锁定。\(\theta=1\)：经典波利亚，收敛到单纯形内部。

### 6.2. 混合相中的衰减

独立滴答给出

\[
\Gamma=-\frac1{\Delta t}\ln\bigl|\langle e^{-i c_\alpha k\Delta t}\rangle\bigr|\approx\tfrac12\mathrm{Var}(c)\,k^2\Delta t.
\]

原先的 \(\Gamma=\mathrm{Var}(c)\,k^2\Delta t\) 差因子 \(1/2\)。

二阶波动方程在 \(c\) 跳变时，单次实现的能量**增长**（参量泵浦）。\(\langle|A|\rangle\) 是错误测度。正确测度是 \(|\langle\psi\rangle|\)。

### 6.3. 锁定之后

\(\Gamma\to 0\)。洛伦兹不变性动态恢复。残余“外来”滴答按 \(k^{-(\theta-1)}\) 衰减。

### 6.4. 有效时间维数

\[
d_T=\frac{(\sum p_\alpha)^2}{\sum p_\alpha^2}\in[1,3],
\]

模拟中可见 \(3\to 1\) 转变。

## 7. 数值实验

代码：`bartini_plus/experiments.mjs`。

运行：`node bartini_plus/experiments.mjs`。

钟速 \(c=(0.18,0.40,0.62)\)，\(\Delta t=0.4\)，模态格点 \(N=128\)。

### L0. 对照 \(\theta=0\)

64 次实现，模态 \(2,4,6,8,10\)。\(\Gamma>0\)；\(\Gamma\) 随 \(k^2\) 增大；\(\beta_{\mathrm{fit}}/\beta_{\mathrm{th}}-1=-2.9\%\)。

### L1. 瓮

| \(\theta\) | \(n_0\) | lock | lock 中位数 | 终末 \(d_T\) | 赢家 |
|---|---|---|---|---|---|
| 0 | 1 | 0 | — | 3 | — |

### L2. 锁定前后的噪声

\(\theta=2\)，\(n_0=25\)，64 次，lock 中位数 1475。锁定后的 \(\Gamma\) 远小于锁定前。

### L3. 巴尔蒂尼–生命

\(48\times 48\) 格子。规则 B3/S23、B36/S23、B3/S234。初值：康威滑翔机。“有结构”：3–40 个活细胞。

| 制度 | 结束时有结构的比例 |
|---|---|
| \(\theta=0\)，混合 | \(4.2\%\) |
| \(\theta=2.5\)，锁定 | \(47\%\) |
| 锁定，赢家 B3/S23 | \(75\%\) |
| 锁定，赢家 B36/S23 | \(85\%\) |
| 锁定，赢家 B3/S234 | \(0\%\) |
| 随机汤，混合 | \(0\%\) |
| 随机汤，锁定 | \(4\%\) |

混合摧毁滑翔机。锁定仅在赢家规则支持滑翔机时保留它。B3/S234 使种群爆炸。在模型内部：观察者只可能出现在锁定之后，且只在赢家之钟“支持生命”的世界里。

**玩具理论成功标准：** 预先登记的 10/10 项判定通过。

## 9. 对“每一瞬间都在选择”的直接回答

否。在巴尔蒂尼+中，锁定之后只有一只钟在走。随机选轴是**早期混合相**与**不同实现**的性质，不是已锁定世界里每一个滴答的性质。若模型成立，现在的外来滴答稀少，并按 \(k\) 的幂衰减。
